既存NASの使い方

NAS本体は買い直さず、UGREEN DH4300 Plusに20TB HDDを4本追加します。速度の役割を分けることが重要です。

TIER 1 / LOCAL NVMe

Mac・PGXの4TB SSD

実行中モデル、Docker、キャッシュ、動画処理中間ファイル。速度が必要なデータは各サーバーへコピーして使う。

TIER 2 / NAS

UGREEN + N300 20TB×4

RAID6で約40TB。モデル原本、動画素材、RAG文書、成果物、各サーバーのバックアップを共有。

TIER 3 / OFFSITE

S3・GCS・別拠点

重要データだけを別障害ドメインへ。RAIDはディスク故障対策であり、誤削除・災害・ランサムウェアのバックアップではない。

ℹ️
NASは2.5GbEの倉庫として使う。

DH4300 Plusは1×2.5GbEなので、10GbEのMac/PGXより遅いです。巨大モデルや大量動画をNAS上から直接処理せず、ジョブ開始時にローカル4TB SSDへステージングします。
