# Claude Code超入門教科書 紹介動画 台本

## 1. つかみ

AI研修を受けたのに、自分の席へ戻ると、何から始めればよいのか分からない。聞いたときは理解できたのに、同じ画面を前にすると手が止まる。そんな経験はありませんか。この教科書は、その最初の一歩を、自分の仕事机で再現するための案内書です。

## 2. この教科書は何が違うか

この教科書では、コードを一行も書きません。覚える特別な入力もありません。画面操作に慣れていない方が、枠の中の依頼文をそのまま使い、一度に一つずつ進められます。分からない画面では、先へ進まず止まることも、正しい進め方として扱います。

身につける流れは、読む、頼む、確かめるの三つです。まず、渡した資料を読んでもらいます。次に、何をしてほしいかを文章で頼みます。最後に、返答だけを信じず、できたものを自分の目で確かめます。Claude Codeを、新人アシスタントとして扱う感覚です。

## 3. 安全の4つの約束

Claude Codeは、質問に答えるだけではありません。許可した仕事場所のファイルを読み、新しいファイルを作ることもできます。手を動かせるからこそ、任せる範囲と確認方法が大切です。そこで、この教科書では、安全の四つの約束を最初に身につけます。

一つ目は、練習用コピーで試します。原本は残し、コピーだけを使います。二つ目は、秘密を貼りません。パスワードや本物の顧客情報を入力せず、架空の内容で練習します。この二つで、大切な資料と情報を守りながら、安心して試せます。

三つ目は、削除、送信、公開、購入の前で止まります。取り返しにくい作業は、自分で理解してから進めます。四つ目は、「できた」を成果物と証拠で確認します。ファイルを実際に開き、頼んだ内容になっているかを確かめます。返答だけで、終わりにしません。

## 4. 進め方

教科書は、第0章から終章までの全十四章です。基本は一章十五分から三十分で、今日は一章だけでもかまいません。練習に使うファイルは、ページからまとめてダウンロードできます。一章ごとに、ゴール、たとえ、練習、できたの確認がそろっています。

## 5. クローズ

最初から全部を覚える必要はありません。読む、頼む、確かめるを、一つずつ自分の席で試してください。ご案内はここまでです。それでは、第0章からどうぞ。この動画はAIでフル生成しています。動画制作者は一切録音や編集をしておらず、10分ほどで生成しています。
